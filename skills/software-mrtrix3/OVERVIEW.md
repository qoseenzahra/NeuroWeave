## 选择规则

- 优先选择与目标产物对应的独立命令；只有明确需要连续多个步骤时才选择 Pipeline。
- 同一 DWI 可以作为响应函数与 FOD 估计的共享输入；响应输出按组织类型连接。
- 按已安装版本的命令契约解释选项，未接入选项不得自行拼接。
- 先确认目标产物和已有输入；只选择必要步骤，已有数据或历史结果优先复用。
- 输入缺少时先查询目录并请求用户绑定；不要自动追加生成该输入的步骤。
- 独立操作选择 Method；确需固定组合时选择 Pipeline，并检查每一步输入输出。
- 软件工具 Skill 用于选择实现，任务 Skill 用于组织需求，不因为同时匹配两类 Skill 重复添加方法。

## 适用情况

- 用户明确使用 MRtrix3，或任务已确定为影像、扩散信号、FOD、纤维束及连接组处理。
