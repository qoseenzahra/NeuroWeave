# ants

选择已接入的 ANTs 配准方法，确定移动影像、参考影像及配准策略。

## 统筹目录

1 个独立方法，0 个组合流程，0 个尚未接入的规划能力。

Skill 负责选择、解释方法与复用已有输入。执行契约唯一保存在 methods/；组合连接保存在 pipelines/；本 Skill 的方法角色见 skill.json 的 method_refs。

先 list_skill_methods（kind=method/pipeline/capability）定位，再 read_skill_method 或 read_skill_pipeline 按需查看参数和端口，不将全部方法手册塞入上下文。

## 选择规则

- 检查移动与参考影像的模态、方向和空间，按需求选择变换类型。
- 现有变换复用应查询独立的变换应用方法，不默认再次估计配准。
- 先确认目标产物和已有输入；只选择必要步骤，已有数据或历史结果优先复用。
- 输入缺少时先查询目录并请求用户绑定；不要自动追加生成该输入的步骤。
- 独立操作选择 Method；确需固定组合时选择 Pipeline，并检查每一步输入输出。
- 软件工具 Skill 用于选择实现，任务 Skill 用于组织需求，不因为同时匹配两类 Skill 重复添加方法。

## 适用情况

- 需要刚体、仿射或 SyN 配准，并明确目标参考空间。

## 限制

- 这里只统筹已登记入口；目录收录不代表覆盖软件全部命令或参数。
- 环境探测与运行证据分别显示；合成数据测试不代表真实数据的科学有效性。
- 尚无 Method 的规划能力只能提供说明，不能当作可执行步骤。

只调用登记的现有软件、库或原始脚本；环境可用不代表已完成真实数据验证。实际运行须检查输入、节点、参数，并通过用户确认后的 Runner。
