# Skill 专属指导整理

`skill.json` 只存本 Skill 特有的适用情况、选择依据、限制和实质性示例。这些字段可以省略；不得为了满足非空校验而批量复制平台话语、替换 Skill 名称，或从目录名称推断执行能力。

本次核对 105 个规范 Skill，删除 533 条通用选择规则、391 条通用限制、134 条模板适用情况和 77 个占位示例。按当前 Method/Pipeline 契约及已整理参考资料补充并保留指导后，45 个 Skill 有额外指导，60 个直接使用已有职责、方法契约和按需资料。后者不是待填满的空白模板。

ADNI 的当前入口实际为目录巡检与 DICOM 转换，因此移除暗示专属字段处理脚本的模板。其他整理包括 dcm2niix 预设选择、ASL 定量前提、PET 参考区、FreeSurfer 产物空间、BIDS 文件映射、模型目标区分、UKB 病例与随访定义等。限制以实际实现为准，例如 MNE ICA 可自动识别 EOG/ECG 关联成分并合并明确的排除索引，不能误写成完全不自动检测伪迹。

共享政策由现有 `SKILL_PROMPT` 维护一次；SkillLoader 概览不再重复工具读取说明或生成空栏目。已选 Skill 的专属适用情况、选择规则与限制传给模型；无额外指导时只传职责。API 保留稳定的空列表投影，Skill 详情只展示有内容的栏目，并只展示一次职责说明。

本次不修改 Method、Pipeline、Runner、模型代码、Skill 的方法引用或参考文档正文，不改变已保存任务、用户 Pipeline 和草稿。科学背景可继续通过显式登记的 `references` 按需读取。

原生定义校验允许省略指导，并检查存在的文本列表类型、非空文本和列表内重复。回归检查覆盖跨 Skill 的重复话语、无指导条目的加载/API/页面展示，以及平台政策和专属限制进入模型的边界。
