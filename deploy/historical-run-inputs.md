# 从历史运行结果选择输入

同一数据集分阶段处理时，可以直接复用旧运行登记的输出。例如先为各样本生成 5TT，之后只选择重新生成 FOD 和纤维追踪，将旧 5TT 作为追踪输入，不再生成或复制 5TT。

## 操作

1. 选择原来登记的数据集，选择本次需要执行的方法，然后锁定流程。
2. 在参数调整阶段，找到对应文件输入（例如“已有 5TT 影像”），点击 **从历史运行结果选择**。
3. 选择之前运行的对应步骤输出。候选按运行时间倒序排列；每次查询 10 次历史运行，可翻页查找更早结果。
4. 核对样本匹配预览。全部样本唯一匹配后，点击 **应用到 N 个样本**。样本预览每页 20 项，长路径换行，底部操作保持可见。
5. 绑定其他输入，审阅参数并执行 Dry-run，再按现有方式选择 Slurm 节点、资源和并行数量后运行。

只需要一个已有输出的输入槽使用此入口，其他输入可继续从数据集选择或连接本次流程的上游输出。绑定后显示历史运行来源，关闭并重新打开任务仍会保留。更换原数据集需要先解锁流程。

## 匹配和检查

- 使用原运行快照中的数据集 ID、数据集路径、样本 ID 和样本相对目录核对身份，不依据 `sample_0001` 等执行目录编号推断样本。当前样本显示顺序变化不会改变对应关系。
- 只采用已经结束的运行中成功步骤登记的、与当前输入类型一致的输出。部分失败运行的成功步骤仍可使用，但所选输出组必须覆盖当前全部样本。
- 缺失、重复、文件类型不符、不同样本指向同一文件等情况会显示具体原因，不能直接应用。当前一次选择一个历史运行的一个输出组，不自动拼接多个运行的零散样本。
- 预览和 Dry-run 检查路径、类型、大小和绑定后的修改时间；提交前重新核对来源及样本覆盖。执行节点读取前还会核对已有的文件 SHA-256，防止旧输出被替换后继续运行。
- 历史引用只授权已登记的具体输出，普通文件选择的数据根目录限制保持原状。Slurm 所选节点必须能读取这些原路径，当前 `/home/data` 共享输出支持跨节点读取。
- 原文件保留在原位置，平台不复制。后续任务依赖这些文件，因此不要删除或移动正在被引用的旧输出。文件变化需要重新选择、审核；不会静默改绑其他输入。
- 影像空间、配准和科学参数仍由现有方法要求及其预检决定；路径匹配本身不证明 5TT 与 FOD 已正确对齐。目录输出目前核对来源、存在性和目录修改时间，不提供完整递归内容快照保证。
- 旧运行如果缺少可恢复的样本身份或具体输出登记，将无法可靠选择；不会猜测归属。单样本旧运行可使用其原始数据集快照识别样本。

## 维护与验证

`bakend/app/historical_inputs.py` 管理来源和身份核对；输入仍沿用 `existing_path` 并附加历史引用元数据。SQLite 不需要新表或迁移。原 Skill、科学脚本及算法参数没有变化。

自动化回归：`bakend/tests/test_historical_inputs.py` 覆盖 API、修订号冲突、样本顺序、缺失和重复输出、旧存储记录、重试来源、文件替换和输入目录边界。界面合成测试入口可通过 `cd frontend` 后执行 `node tests/serve-historical-input-harness.mjs` 打开，结束后按 Ctrl+C 关闭。

服务器集成验证使用 `scripts/smoke_historical_inputs.py --root /home/data/neuroweave/smoke/<新的测试目录>`。需要显式提供已部署的共享 Worker 和 Python 配置；脚本只创建合成影像和隔离数据库，不读取生产数据库或 `.env`。它调用现有 Nilearn 方法执行两轮、每轮两个样本，在第二轮倒置样本顺序，并验证实际 Slurm Worker 读取正确的旧输出且未复制到原数据目录。证据保留在测试目录的 `evidence.json`。

2026-09-08 验证结果：后端 198 项测试及 496 项子测试通过，前端 8 项回归、类型检查、lint 和 Linux 构建通过。浏览器实测 775px / 390px 宽度下的 63 样本预览、翻页、应用和缺失样本禁用状态正常。

真实 Slurm 作业 276–279 全部 `COMPLETED / 0:0`。第一轮 subject-A 在 node01、subject-B 在 node02 生成结果；第二轮交换顺序及节点，分别从旧运行自己的输出路径读取。原输出 SHA-256 不变，原始目录仍只有两份合成输入。运行记录位于隔离目录 `/home/data/neuroweave/smoke/history-d2abff1-20260908T0650/evidence.json`；此验证证明历史输入的身份绑定与跨节点复用，不替代具体研究数据的科学质量检查。
